Install on your laptop

brew install --cask aiherd-dev/aiherd/aiherd

Homebrew · macOS 14+ · Apple Silicon or Intel

Setup, pairing & updates

Install Homebrew first if needed. Open AIHerd from Applications; it starts the herd automatically. Pair your phone using the app's herd connection menu.

Update with brew upgrade --cask aiherd.

Without Homebrew, download the signed macOS .pkg for Apple Silicon (aarch64) or Intel (x86_64) from the latest release.

curl -fsSL https://aiherd.dev/install.sh | bash

Run as your normal user · systemd · x86_64 / ARM64

Setup, pairing & updates

The herd runs in the background with systemd, including after logout and reboot. The installer may ask for sudo to keep the service running after logout. Models download when first needed.

Sign in to expose your herd. Open the printed sign-in URL on your phone or another computer.

export PATH="$HOME/.local/bin:$PATH"
aih login

Add your mobile device, then scan the QR code or open the link and approve pairing in the terminal.

aih join

Run the install command again to upgrade. Check the service with systemctl --user status aih.service; read logs with journalctl --user -u aih.service -f.

irm https://aiherd.dev/install.ps1 | iex

PowerShell as Administrator · x64 Windows 10 1809+ / Server 2019+

Setup, pairing & updates

The installer verifies the download checksum, installs into Program Files, and starts the service at boot. Run the install command again to upgrade.

Keep PowerShell elevated to sign in and pair your phone. Complete browser sign-in, then scan the QR code and approve pairing in the terminal.

aih login
aih join

Open AIHerd from the Start menu using the account you installed with; no Administrator needed. Check the service with Get-Service AIHerd. Its terminals run as LocalService. RDP must already be enabled. Model summaries are not available on Windows.

One project. The same sessions.

Build at your desk.
Keep going anywhere.

You're building Trailboard, a small launch checklist. Claude handles the app in cmux. A second session in Cursor writes the tests. Here's how the work follows you through the day.

01 / At your desk

Start where you already work.

Open Claude Code in cmux and start a Cursor session alongside it. Ask Claude to build the checklist and Cursor to cover the task counts with tests. AIHerd follows both sessions in the tools you already use.

02 / Away from your desk

Check in from your phone.

You step out. Open the AIHerd mobile app and see the same Claude and Cursor sessions. Claude has finished the first version and asks what to do next.

Send a follow-up: “Add localStorage persistence so the checklist survives a reload.” The prompt goes back to Claude in the original cmux session.

Your laptop keeps doing the work. Your phone keeps it moving.

03 / At another laptop

Your shell survives a change of IP.

Open a shell on your development machine and run the tests against the files your agents changed.

aih ssh demo-laptop
cd ~/trailboard
python3 -m unittest -v

Switch Wi-Fi or move to a hotspot: your shell keeps running on the herd. aih ssh retries and resumes the same session when connectivity returns, even if your client IP changed.

The red banner shows the interruption and retry status. It clears when the connection recovers, and you carry on in the same shell.

How recovery works

The remote herd must keep running. The CLI reconnects to it and resumes the existing SSH session, without requiring a fixed client IP.

04 / Time to try the app

Open the desktop. See what they built.

Trailboard is also running on your Linux test VM. Connect with aih rdp and try the app in its browser: move a task, add another, and check how the result feels.

aih rdp demo-linux

RDP opens a Linux or Windows herd's desktop. For your Mac's desktop, use aih vnc demo-laptop.

05 / In a Linux VM

Your sessions, from a terminal.

Later, you're working in a Linux VM. Use the pane picker to find your laptop's Claude or Cursor session, open it, read its output, and send the next prompt.

aih remote demo-laptop pane

aih pane opens the local herd. aih remote demo-laptop pane reaches the saved laptop connection.

Back at your desk, continue in the same cmux and Cursor sessions.
