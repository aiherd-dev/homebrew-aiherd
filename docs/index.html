1. Install and start the service

Run the Windows remote gateway as a background service, including after logout and reboot. Open PowerShell as Administrator.

Requires a Windows ZIP in the latest release. If none is listed yet, wait for the next release.

1. Install and start the service

Invoke-WebRequest -UseBasicParsing https://aiherd.dev/install.ps1 -OutFile "$env:TEMP\aiherd-install.ps1"
powershell.exe -NoProfile -ExecutionPolicy Bypass -File "$env:TEMP\aiherd-install.ps1"

2. Sign in

& "$env:ProgramFiles\AIHerd\aih.exe" login

3. Pair your mobile device

& "$env:ProgramFiles\AIHerd\aih.exe" join

Open the sign-in URL in your browser. Then scan the pairing QR code on your phone and approve it in PowerShell.

x64 · Windows 10 1809 / Server 2019 or newer. Native PowerShell terminals, SSH and forwarding. This package is the remote gateway; desktop monitoring and local AI models are available on macOS and Linux.

The service runs as LocalService. Its terminals use that account's permissions. Rerun the installer to upgrade; credentials are preserved and open shells close during restart.

Check the service: Get-Service AIHerd.
