You're building Trailboard, a small launch checklist. Claude handles the app in cmux. A second session in Cursor writes the tests. Here's how the work follows you through the day.

01 / At your desk

Start where you already work.

Open Claude Code in cmux and start a Cursor session alongside it. Ask Claude to build the checklist and Cursor to cover the task counts with tests. AIHerd follows both sessions in the tools you already use.

02 / Away from your desk

Check in from your phone.

You step out. Open the AIHerd mobile app and see the same Claude and Cursor sessions. Claude has finished the first version and asks what to do next.

Send a follow-up: “Add localStorage persistence so the checklist survives a reload.” The prompt goes back to Claude in the original cmux session.

Your laptop keeps doing the work. Your phone keeps it moving.

03 / At another laptop

Run the tests yourself.

Cursor says the tests pass. From another laptop, open a shell on your development machine with aih ssh. Go to the project and run the suite yourself, against the files your agents just changed.

aih ssh demo-laptop
cd ~/trailboard
python3 -m unittest -v

04 / Time to try the app

Open the desktop. See what they built.

Trailboard is also running on your Linux test VM. Connect with aih rdp and try the app in its browser: move a task, add another, and check how the result feels.

aih rdp demo-linux

RDP opens a Linux or Windows herd's desktop. For your Mac's desktop, use aih vnc demo-laptop.

05 / In a Linux VM

Your sessions, from a terminal.

Later, you're working in a Linux VM. Use the pane picker to find your laptop's Claude or Cursor session, open it, read its output, and send the next prompt.

aih remote demo-laptop pane

aih pane opens the local herd. aih remote demo-laptop pane reaches the saved laptop connection.

Back at your desk, continue in the same cmux and Cursor sessions.

Set up your laptop

Install AIHerd on the computer where your agents run, then pair your phone or another computer.

brew install --cask aiherd-dev/aiherd/aiherd

macOS 14 (Sonoma) or newer · Apple Silicon or Intel

Install Homebrew first if needed. Then open AIHerd from Applications; it starts the herd automatically. To update, run brew upgrade --cask aiherd.

Without Homebrew, download the signed macOS .pkg for Apple Silicon (aarch64) or Intel (x86_64) from the latest release.

Install on a headless Linux machine over SSH. The herd runs in the background with systemd, including after logout and reboot.

1. Install and start the service

curl -fsSL https://aiherd.dev/install.sh | bash

x86_64 / ARM64 · systemd · fully static Linux binaries. Run as your normal user; the installer may ask for sudo to keep the service running after logout. Run the same command to upgrade. Models download when first needed.

2. Sign in to expose your herd

export PATH="$HOME/.local/bin:$PATH"
aih login

Open the printed sign-in URL on your phone or another computer.

3. Add your mobile device

aih join

Scan the QR code or open the link, then approve pairing in the terminal.

Check the service: systemctl --user status aih.service.
Logs: journalctl --user -u aih.service -f.

Install the native Windows dashboard and its service for PowerShell terminals, SSH and RDP forwarding. The service starts automatically at boot.

1. Open PowerShell as Administrator and install

Invoke-WebRequest -UseBasicParsing https://aiherd.dev/install.ps1 -OutFile "$env:TEMP\aiherd-install.ps1"
powershell.exe -NoProfile -ExecutionPolicy Bypass -File "$env:TEMP\aiherd-install.ps1"

x64 Windows 10 1809 / Server 2019 or newer. Verifies the download checksum and installs into Program Files. Run the same commands to upgrade.

2. Open AIHerd from the Start menu

Use the Windows account you installed with. The desktop app connects to the installed service by default and does not need to run as Administrator. No separate .NET installation is needed.

3. Sign in, then pair your phone

& "$env:ProgramFiles\AIHerd\aih.exe" login
& "$env:ProgramFiles\AIHerd\aih.exe" join

Keep PowerShell elevated. Complete browser sign-in, then scan the pairing QR code and approve the request in the terminal.

Check the service with Get-Service AIHerd. The service runs as LocalService; its terminals use that account. RDP must already be enabled on Windows. Model summaries are not available on Windows.
